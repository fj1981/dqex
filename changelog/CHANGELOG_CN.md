# 更新日志

## [1.1.0] - 2026-08-25
### 新增
- 工作区标签页设置功能：支持数量上限与固定标签页
- Web 服务认证策略升级：本机回环（127.0.0.1/localhost）免认证，外部来源令牌校验，白名单可选增强，`--no-auth` 完全禁用认证模式
- 开源构建标签（`-tags opensource`）支持，控制"关于"弹窗是否显示项目链接与更新日志
- "关于"弹窗新增 GitHub 仓库地址与联系信息链接
- GitHub Issue 模板：Bug 报告与功能请求
- CI 工作流：跨平台自动构建与发布包

### 优化
- Web 服务本地启动日志优化：回环监听时简化认证提示，突出"本机免认证"
- 代码格式调整与依赖导入顺序优化

### 文档
- 新增贡献指南（CONTRIBUTING.md）、行为准则（CODE_OF_CONDUCT.md）与安全策略（SECURITY.md）
- README 新增 AI 对话演示 GIF

## [0.6.0] - 2026-08-21
### 新增
- 数据库方言适配层独立封装，为跨数据库能力提供稳定基座
- 完善项目文档，提供中英文双语说明

## [0.5.0] - 2026-08-21
### 新增
- 端口占用检测：Web 服务启动前自动检测端口占用，支持终止占用进程后重试绑定或直接打开已有服务，支持 macOS/Linux/Windows 三平台
- `dqex stop` 命令：查找并终止其他正在运行的 dqex 进程

### 优化
- macOS 下启动时自动复用浏览器已有标签页：若已打开相同地址则直接激活，不再新开标签（支持 Chrome / Safari / Firefox / Edge / Brave）
- 数据库类型改用品牌色图标标识，连接选择下拉升级为两行布局：名称/短名与地址分列展示，选中项高亮，完整地址支持悬停查看

### 修复
- 连接选择器在窄栏下选中内容被整体截断的问题，名称与地址信息层级重构后不再互相挤压
- 导出后再导入报 SQL 语法错误（Error 1064）的问题：文本类型字段（如 mediumtext 存储的 JSON）含单引号等特殊字符时，SQL 字面量未按目标数据库方言规则转义，导致导入中断
