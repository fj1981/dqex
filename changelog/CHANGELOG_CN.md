# 更新日志

## [1.2.1] - 2026-08-27
### 优化
- 迁移写入前自动挂起目标库外键校验（连接级开关），含自引用外键的库迁移不再因行序报错
- 迁移表按外键依赖拓扑排序，父表优先创建
- 依赖 infrakit 升级至 v1.2.0：批量写入合成多值语句，迁移写入提速；进度页显示当前表名
- 选表步骤步骤间切换保留已加载的库/表与勾选状态；切换连接自动清空旧选择，避免残留库名混入

### 修复
- 多库场景下的选择与迁移体验：此前按库勾选表/对象时库名归属错乱、切换连接后残留旧库选择；现已支持按库精确选择（未展开的库勾选后自动加载并级联全选），迁移支持一次勾选多个源库逐库执行（目标库未配置时与源库同名并自动创建）
- 导出双段模式下进度长时间停滞在 0 及对象阶段进度百分比回退的问题
- PG/Kingbase 双引号限定名（`"schema"."table"`）导致数据读取失败的问题
- 迁移 DataOnly 模式下进度无法做满的问题

## [1.2.0] - 2026-08-26
### 新增
- 对象树分级加载：库列表 → schema（带表计数）→ 对象清单逐级懒加载，未展开节点灰显提示，展开更轻快（参考 Navicat 交互）
- 元数据缓存与刷新：分级接口 10 分钟缓存加速重复展开；对象树顶部刷新按钮与库/schema 节点悬停刷新，刷新时绕过缓存直查数据库
- SQL 智能提示支持 PG 系 schema 分层：`库名.` 后补 schema 名，`schema.` 后补表/视图
- 导出表过滤支持 `库.schema.表` 三级限定名（PG 系可按 schema 精确指定）

### 优化
- 元数据枚举聚合下沉数据库方言层：一次往返获取 schema 列表与表计数；系统库/系统用户自动过滤（MySQL 系统库、Oracle 系统用户、PG/Kingbase 系统 schema）

### 修复
- Kingbase 连接下对象树仍显示系统 schema `sys` 的问题
- 依赖 infrakit 升级至 v1.1.0：修复 PG 系方言 `?` 占位符导致的元数据获取/结构导出失败

## [0.5.0] - 2026-08-21
### 新增
- 端口占用检测：Web 服务启动前自动检测端口占用，支持终止占用进程后重试绑定或直接打开已有服务，支持 macOS/Linux/Windows 三平台
- `dqex stop` 命令：查找并终止其他正在运行的 dqex 进程

### 优化
- macOS 下启动时自动复用浏览器已有标签页：若已打开相同地址则直接激活，不再新开标签（支持 Chrome / Safari / Firefox / Edge / Brave）
- 数据库类型改用品牌色图标标识，连接选择下拉升级为两行布局：名称/短名与地址分列展示，选中项高亮，完整地址支持悬停查看

### 修复
- 连接选择器在窄栏下选中内容被整体截断的问题，名称与地址信息层级重构后不再互相挤压
- 导出后再导入报 SQL 语法错误（Error 1064）的问题：文本类型字段（如 mediumtext 存储的 JSON）含单引号等特殊字符时，SQL 字面量未按目标数据库方言规则转义，导致导入中断
